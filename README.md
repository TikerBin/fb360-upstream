# FB360 Panorama Upstream

Free-license 360° equirectangular landscape panoramas, processed to be Facebook-360 ready,
published as an RSS/JSON feed for incremental polling.

## Subscribe
- RSS 2.0: https://raw.githubusercontent.com/TikerBin/fb360-upstream/main/feed.xml
- JSON Feed 1.1: https://raw.githubusercontent.com/TikerBin/fb360-upstream/main/feed.json

## Contract
- `items.json` is the single source of truth. `feed.xml` / `feed.json` are GENERATED by
  `build_feed.py` — never edit them directly; fix `items.json` and rebuild.
- Each item's `pubDate` / `date_published` is the Beijing-time date the item was collected
  and added upstream. Consumers can incremental-sync by taking only items newer than
  their last sync.
- Item payload: stable `id`; `theme`; `location` / `country`; `author`, `license`,
  `license_url`; `source_url` (original file page, permanent); `download_url`
  (RSS enclosure / JSON attachment — the finished JPG under `media/`, image/jpeg,
  with byte size; JSON also carries `_sha256`); `original_download_url` + original
  dimensions; `shoot_date` (only when verifiable); caption in English (feed outputs are English-only; the source items.json retains EN/FR/ZH).
- Finished file spec: 6000×3000 equirectangular JPEG (strict 2:1) with GPano XMP
  (ProjectionType=equirectangular, UsePanoramaViewer=True) + EXIF Make RICOH /
  Model RICOH THETA S — upload to Facebook as a normal photo and it is recognized
  as a 360 photo. Do not re-save through tools that strip metadata.
- License gate: PD / CC0 / CC BY / CC BY-SA only, verified per item. CC BY / CC BY-SA
  items require the attribution line included in their captions when posted.
- Feed window: at most 420 items; older items age out as new batches are added.
